# 소담섬 · Sodam Island

작은 섬에서 자기 속도로 살아가는 Windows용 2D 힐링 시뮬레이션입니다.
기획 원문의 “힐링 시뮬레이션 (레퍼런스: 동물의 숲)”을 바탕으로 만들었습니다.
캐릭터, 섬, 건물, 식물은 직접 구성한 도형 그래픽이며 배경음과 효과음도 코드로 생성합니다.

## 실행

- Unity **6000.6.7f1**에서 `Assets/Scenes/SodamIsland.unity`를 열고 Play를 누르세요.
- Windows 빌드가 있다면 `Builds/SodamIsland/SodamIsland.exe`를 실행하세요. 옆의 데이터 폴더도 필요합니다.
- Unity 메뉴 `Sodam > Build Windows game`으로 다시 빌드할 수 있습니다.

## 섬 생활

| 조작 | 기능 |
|---|---|
| WASD / 방향키 | 걷기 |
| 빈 땅 클릭 | 해당 위치로 걷기 (장애물은 직접 돌아가 주세요) |
| E / 하단 초록 버튼 | 가까운 시설과 상호작용 |
| B | 벤치, 랜턴, 화분 꾸미기 모드 |
| H | 도움말 |
| Esc | 창 닫기 / 꾸미기 취소 / 일시 정지 |

1. 사과나무 가까이에서 E: 사과 3개, 나뭇가지 1개를 얻어요. 다음 날 다시 열립니다.
2. 텃밭에서 E로 씨앗 심기 → E로 물 주기 → 45초 기다린 뒤 E로 당근 2개 수확.
3. 연못 남쪽에 서서 E: 입질을 기다린 뒤 표시가 초록 구간일 때 E로 물고기를 낚아요.
4. 토리와 이야기하거나 사과 2개를 선물해요. 선물은 하루 한 번 25잎을 줍니다.
5. 모모의 상점에서 수확물을 판매하고 씨앗을 구입해요.
6. 하루 목표 세 개를 달성하면 오른쪽 일지에서 80잎과 씨앗 3개를 받아요.
7. B로 가구를 선택하고 빈 땅을 클릭하세요. 하나에 35잎과 나뭇가지 2개가 필요해요.
8. 집 앞에서 E를 눌러 다음 날로 쉬세요. 물을 준 작물은 다음 날 모두 자라요.

## 저장

20초마다, 주요 행동 후, 종료 시 JSON으로 자동 저장합니다. 오른쪽 위 저장 버튼도 있습니다.
Windows 저장 위치: `%USERPROFILE%/AppData/LocalLow/Sodam Studio/Sodam Island/sodam-island.json`.
이전 저장은 `.bak` 파일로 보관합니다. 게임이 꺼진 동안에는 작물 성장 시간이 흐르지 않습니다.
일시 정지와 대화 중에도 작물 성장 시간이 멈춥니다.

## 구현 범위

싱글플레이 섬 하나, 7그루의 사과나무, 6칸 텃밭, 낚시 미니게임,
주민 대화와 선물, 판매/씨앗 상점, 하루 목표, 3종 꾸미기, 날짜 전환과 로컬 저장을 제공합니다.
계절 변화, 온라인 플레이, 실시간 달력, 실내 공간은 포함하지 않습니다.
한국어는 운영체제에 설치된 맑은 고딕 등 시스템 글꼴을 사용합니다.
